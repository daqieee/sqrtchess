# 根号棋规则与实现细则

## 一、规则原文

1. 棋盘为 11x11 的交叉线，所有棋子均位于格点上，对战双方为镜像布局，每名玩家在最靠近自己的
   两行有初始棋子：

   ~~~
   ---棋盘中心---
   无 1 1 1 1 1 1 1 1 1 无
   无 4 8 5 2 9 2 5 8 4 无
   ---棋盘边缘---
   ~~~

2. 每个棋子有其对应的「棋子大小」，对应一个整数。棋子在移动时，必须恰好移动 sqrt(棋子大小) 格，
   并必须移动到格点上；如果无法落到棋盘内的合法格点上就不能移动。棋子移动无视「路径」上的棋子，
   只看落点格是否有棋子：如果有我方棋子则无法移动，如果有敌方棋子则执行吃子。
3. 当一个棋子进行吃子时，会将自己的「棋子大小」+= 被吃掉的敌方棋子的「棋子大小」。
4. 当一方失去所有棋子时，输掉游戏。
5. 如果在任意一次行动后，双方都有棋子，但有一方的所有棋子均没有合法移动格，进入平局判定。
6. 如果双方合计连续 50 步没有吃子，进入平局判定。（本项目默认采用 100 步，见实现口径）
7. 平局判定的流程为：分别统计双方拥有的棋子数量，和双方的棋子的「棋子大小」总和。
   如果有一方的两项均大于另一方，则这一方胜利；否则所有其余情况均为平局。

## 二、坐标与棋盘

* 棋盘 11x11 = 121 个格点，列用 `a`..`k`（左到右），行用 `1`..`11`（下到上）。
* 白方（先手）在下：第 1 行是 `.W4W8W5W2W9W2W5W8W4.`，第 2 行是 9 枚大小 1 的棋子。
* 黑方在上：第 11 行、第 10 行与白方镜像（这两行本身是回文，所以上下翻转与 180 度旋转等价）。
* 每方 18 枚棋子，初始大小总和 56（9x1 + 4+8+5+2+9+2+5+8+4 = 56），双方合计 112。

## 三、走法（实现口径）

大小为 n 的棋子的合法位移是全部整数解 (dx, dy)：

~~~
dx*dx + dy*dy == n  且  (dx, dy) != (0, 0)   且   落点仍在棋盘内
~~~

常见的：

| 大小 | 位移 | 说明 |
| --- | --- | --- |
| 1 | (±1,0), (0,±1) | 上下左右 1 格 |
| 2 | (±1,±1) | 斜走 1 格 |
| 4 | (±2,0), (0,±2) | 直走 2 格 |
| 5 | (±1,±2), (±2,±1) | 马步 |
| 8 | (±2,±2) | 斜走 2 格 |
| 9 | (±3,0), (0,±3) | 直走 3 格 |
| 10 | (±1,±3), (±3,±1) | 「长马步」 |
| 13 | (±2,±3), (±3,±2) | |
| 16 | (±4,0), (0,±4) | |

**不能表示成两个整数平方和的大小没有任何走法**，例如 3、6、7、11、12、14、15、19、21、22、23、24……
判定依据是数论中的双平方和定理：n 的所有 4k+3 型素因子的指数都必须是偶数。
实用结论：棋子吃成 3、6、7 之类的数字后会「卡死」在原地，这是规则的自然结果，
也是这个棋种很重要的战术要素（把对手的棋子喂成动不了的大小）。

## 四、吃子

* 只有落点上有敌方棋子时才吃子；吃子后走子方大小 = 原大小 + 被吃棋子大小。
* 被吃棋子从棋盘上移除。
* 整局棋的「棋子大小总和」守恒（吃子只是把对方的大小并进自己身上）。

## 五、结束与判定

判定顺序（每一步之后按此顺序检查）：

1. **吃光**：某一方棋子数为 0 → 另一方胜（原因 `all-captured`）。
   注意双方都空（理论上不会出现）按平局处理。
2. **无子可动**：双方都还有棋子，但至少有一方的所有棋子都没有合法落点 → 平局判定
   （原因 `no-moves`）。注意这一条与「轮到谁走」无关：只要某一方整体动不了就立刻判定。
3. **无吃子**：双方合计连续 100 步（半回合，默认可配置）没有吃子 → 平局判定（原因 `no-capture-limit`）。
   上限可配置（`no_capture_limit` / `--limit`），`None` 或 `off` 表示不判定。
4. **平局判定（规则 7）**：

   ~~~
   若 白子数 > 黑子数 且 白大小和 > 黑大小和  → 白胜
   若 黑子数 > 白子数 且 黑大小和 > 白大小和  → 黑胜
   其余情况（含完全相等、只有一项占优、一项占优另一项落后） → 平局
   ~~~

   判定结果会写在结果的 `detail` 字段里，例如
   `白方 12 子/大小和 61，黑方 9 子/大小和 44`。

5. 认输（`resign`）与协议和棋（`agreement`）由外部宣布，用于棋谱与界面。

## 六、几个容易混淆的点

* 「移动 sqrt(n) 格」是**欧氏距离**，不是曼哈顿距离，也不是「走 n 步」。
* 走子**不经过**中间格点，所以不存在「挡路」「蹩马腿」。
* 吃子只改变**走子方**的大小，不影响棋盘上其它棋子。
* 平局判定对比的是「棋子数量」与「大小总和」，不是「最大棋子」。
* 无吃子上限按**半回合**（一方走一步算一步）计数，吃了子立即清零。11x11 棋盘较大，
  本项目默认取 **100 步**（`DEFAULT_NO_CAPTURE_LIMIT`）；命令行 `--limit`、界面「对局设置」
  均可改成 50 / 150 / 200 / off（不判定）。
* 每方 9 枚大小 1 的棋子只能直走 1 格，开局时它们互相挤在一起，所以初始只有 22 种合法着法。
