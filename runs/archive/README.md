# 归档说明：第一代 AlphaZero 模型（az1 ~ az4）

## 为什么归档

这四个模型都是**对着"进攻优先"的对手训练出来的**：

* 锚点/陪练对手是「吃子基线」（尽可能多吃子）、随机走子、贪心 AI —— 全是进攻型；
* 于是网络的策略退化成「防守反击」：开局尝试进攻，占到子力优势就回家守着，
  占不到就拖到 100 步无吃子判和；
* 自我对弈大量对局以和棋收场，价值头学到的区分度也越来越低。

结论：**作为"能下棋的 AI"它不弱（对随机 0.9、对贪心物质 +41），但棋风已经跑偏，教材也不够多样**，
因此归档，改为先用 Alpha-Beta 引擎建立更全面（战术 + 局面）的新基线，再从头训练。

## 归档内容

| 目录 | 说明 | 关键指标 |
| --- | --- | --- |
| az1 | 第一版纯 AlphaZero（6 轮） | 对吃子基线 0.25 左右 |
| az2 | 加陪练 + 物质先验（6 轮） | 对吃子基线 0.400 |
| az3 | 和棋按原因区分价值 + 陪练对手池（8 轮） | 对吃子基线 0.417，对 az2 0.750 |
| az4 | 200 次模拟 + 叶子吃子搜索 2 层（10 轮） | 对吃子基线 0.400~0.458，物质差 -2.4~-2.8 |

每个目录里都有：

* `best.json` —— 该轮训练出的最强网络（可直接被界面/命令行加载）；
* `net-iterNNN.json` —— 每轮快照；
* `metrics.jsonl` —— 每轮指标；
* `train.log` —— 完整训练日志；
* `games/*.sqg` —— 自我对弈棋谱。

## 还能不能用

能。命令行：

~~~bat
python -m alphazero arena --a runs/archive/az4/best.json --b ab --games 10 --depth 4
python -m alphazero play  --model runs/archive/az4/best.json --sims 200
~~~

界面里：「对局设置 → AlphaZero 权重文件」选到本目录下的 `best.json` 即可。
